# GitHub 基础名词速查

## Repository（仓库）
项目容器，包含代码、文档、配置、提交历史。

## Commit（提交）
一次保存记录，建议每次提交都写清楚“做了什么”。

## Branch（分支）
并行开发线：例如 `main`（稳定）和 `feature/login`（开发中）。

## Pull Request（拉取请求）
发起“请把我的分支改动合并到目标分支”的请求，便于代码评审。

## Issue（议题）
记录问题、需求、任务；可以分配负责人、设置标签和里程碑。

## Fork（派生）
把别人的仓库复制到自己账号下，再自行修改。

## Clone（克隆）
把远程仓库下载到本地。

## Push / Pull
- `push`：把本地提交上传到远程。
- `pull`：把远程最新改动拉到本地。
